================================================================================
DYNAMIC REFRESH LOGIC
================================================================================

The bot now intelligently adjusts its refresh rate:

FAST MODE (10 seconds):
- Triggered when price change ≥ spread threshold
- Ensures quick order updates during volatility
- Maximizes profit opportunities
- Shown in UI: "⏱️ Dynamic Refresh: 10s"

NORMAL MODE (60 seconds):
- Active during price stability
- Reduces API call frequency
- Prevents rate limiting
- Shown in UI: "⏱️ Dynamic Refresh: 60s"

Example:
- Spread set to 1.5%
- Price changes by 1.6% → Switches to 10s refresh
- Price stabilizes (change < 1.5%) → Returns to 60s refresh
